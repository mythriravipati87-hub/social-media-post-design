# social-media-post-design
A technology-themed social media post designed using Canva.
Social Media Post Design Using Canva

Project Overview
This project involves designing a visually appealing, technology-themed social media post using Canva.

 Objective
To understand and apply the fundamentals of graphic design, including composition, typography, color consistency, and visual storytelling.

 Tools Used
- Canva
- PNG image export

Key Features
- Consistent color palette and branding
- Clear typography and visual hierarchy
- Relevant technology-themed icons and graphics
- Engaging headline and call-to-action
- Social media-ready square format

 Learning Outcomes
- Learned basic graphic design principles.
- Practiced arranging text and visual elements.
- Understood the importance of consistent branding.
